# Hedgehog RP (Legacy - React)

</div>

> **Version:** `v1.0.0`
>
> **Current version (Next.js):** [hedgehog-rp](https://github.com/MaSStiK/hedgehog-rp)

**Hedgehog RP (Legacy)** is a social platform for a political role-playing game set in a shared virtual world.

This repository contains the original React version of the platform. The project is in limited maintenance mode and no longer receives new features.

## ✨ Features

- Creation and development of your own countries and their political and economic systems according to your interests
- Publication of news articles and in-game events
- User-friendly editor for articles and posts
- Interaction with other community members
- Diplomatic negotiations, alliances, international relations, and competition for influence on the world stage
- Directory of participants and in-game countries
- Dedicated profiles for users and countries
- News feed with the latest community publications
- Shared world history that evolves through participants’ actions

## 🔗 Related Projects

- 🌍 [Interactive Online Map](https://github.com/MaSStiK/map.hedgehog-rp)
- 📺 [Hedgehog Television](https://github.com/MaSStiK/tv.hedgehog-rp)
- 📊 [Chat Statistics](https://github.com/MaSStiK/stats.hedgehog-rp)

## 🛠️ Technologies

- **React** - Application UI
- **react-dropdown-select** - Custom dropdown lists
- **react-range** - Interactive sliders and range controls
- **react-zoom-pan-pinch** - Image zooming and panning
- **jQuery** - DOM manipulation and utility functions
- **canvas-confetti** - Visual effects and animations
